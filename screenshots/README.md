# Screenshots

This folder is where the main `README.md` expects to find screenshots.
Run the app (web and/or mobile) and save one image per row below with
the **exact filename** listed, and they'll appear automatically in the
main README.

| Filename | Capture this |
|---|---|
| `landing.png` | The public landing page (logged out), showing the hero and the Login/Sign Up buttons in the top corner |
| `signup.png` | The sign-up page |
| `login.png` | The login page |
| `home.png` | The logged-in home/dashboard page |
| `advisory-form.png` | The Crop Advisory input form |
| `advisory-result.png` | The Crop Advisory result (recommended crop + fertilizer/irrigation/diseases) |
| `leaf-disease.png` | The Leaf Disease Detection page with a result showing the disease name and treatment |
| `history.png` | The Advisory History page |
| `about-model.png` | The About Model page (model comparison table) |
| `language-selector.png` | The language dropdown open, showing English / বাংলা / हिन्दी |
| `dark-mode.png` | Any page in dark mode |
| `mobile-home.png` | The Expo app's Home tab on a phone/emulator |
| `mobile-login.png` | The Expo app's Login screen |
| `mobile-advisory.png` | The Expo app's Crop Advisory screen with a result |
| `mobile-leaf-disease.png` | The Expo app's Leaf Disease screen with a result |

PNG or JPG both work. 1200-1600px wide is a good size for README display.
